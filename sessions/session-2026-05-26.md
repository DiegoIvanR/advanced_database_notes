## What I understood
- OLTP: few gb, transactional. A lot of writes.
- OLAP: terabytes, historical data and data analysis a lot of reads.
- OLAP schema has a star schema with facts tables with fks, joined to dimensions tables.
- For example, all user data is stored in a dimension table, the data you want is in the star schema, so at max you only need one join, forget about normalization.
- In contrast in OLTP you would need multiple joins to retrieve the data you want.
- To transfer data from OLTP to OLAP, you'll need to get and transform the data, Extract, Transform and Load (ETL).
